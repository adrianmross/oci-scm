# Changelog

## 0.1.0 — 2026-10-05

- Initial gh-style OCI repository, PR, comment, build run and pipeline commands.
- Optional octx/oci-context target resolution and oidm/oci-idm defaults.
- Credential-free repository config, explicit mutation plans and scoped OCI CLI calls.
- Checksum-verified handoffs, missing/equivalent commit detection, isolated planning,
  dirty-worktree protection, remote binding and readback evidence.
- Dual executable names, shell completion, cross-platform tests and release archives.
- External ReviewMode OCI plugin with project-specific context, comment threads,
  replies and verified single-line comments.
